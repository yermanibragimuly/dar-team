# Контекст проекта DAR TEAM

## Описание проекта
Веб-сайт спортивной команды DAR TEAM (бэкенд на Java Spring Boot, база данных PostgreSQL, фронтенд на Vue 3 / Vite, веб-сервер Caddy/Nginx).

## Основной стек
- **Frontend:** Vue 3 (Options/Composition API), Tailwind CSS, Vite
- **Backend:** Java Spring Boot, PostgreSQL, Redis
- **Инфраструктура:** Docker, Caddy/Nginx, pgAdmin
